# SNS下書き帳 サポートページ

iOSアプリ「SNS下書き帳」の公開用サポートページ・プライバシーポリシーです。
GitHub Pages でホストする想定のリポジトリです。

## ファイル構成

- `index.html` — サポートページ（アプリ概要・機能・FAQ）
- `privacy.html` — プライバシーポリシー

## 公開手順（GitHub Pages）

1. このフォルダの内容を新しいGitHubリポジトリの `main` ブランチ・ルート直下にpushする
2. リポジトリの Settings → Pages で、Source を `Deploy from a branch`、Branch を `main` / `root` に設定する
3. 数分後に以下のURLで公開される

## App Store Connect で設定するURL

- サポートURL: `https://NEW_GITHUB_USERNAME.github.io/NEW_REPOSITORY_NAME/`
- プライバシーポリシーURL: `https://NEW_GITHUB_USERNAME.github.io/NEW_REPOSITORY_NAME/privacy.html`

> `NEW_GITHUB_USERNAME` / `NEW_REPOSITORY_NAME` は実際の新しいGitHubアカウント名・リポジトリ名に置き換えてください。

## 注意事項

- `privacy.html` 内の `YOUR_SUPPORT_EMAIL_HERE` は、実際の問い合わせ用メールアドレスに置き換えてください。
- 旧GitHubアカウントとは関連付けないため、新しいアカウント・新しいリポジトリで公開してください。
