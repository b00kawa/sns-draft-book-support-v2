# SNS下書き帳 サポートページ

iOSアプリ「SNS下書き帳」の公開用サポートページ・プライバシーポリシーです。
GitHub Pages でホストする想定のリポジトリです。

## ファイル構成

- `index.html` — サポートページ（アプリ概要・機能・FAQ・お問い合わせ）。現在は Version 1.2 の内容に対応
- `privacy.html` — プライバシーポリシー

## 公開済みURL

- リポジトリ: https://github.com/b00kawa/sns-draft-book-support-v2
- GitHub Pages: `main` ブランチ / `root` で公開中

## App Store Connect で設定するURL

- サポートURL: `https://b00kawa.github.io/sns-draft-book-support-v2/`
- プライバシーポリシーURL: `https://b00kawa.github.io/sns-draft-book-support-v2/privacy.html`

## 注意事項

- 問い合わせ先は、このリポジトリの GitHub Issues（https://github.com/b00kawa/sns-draft-book-support-v2/issues）です。専用のサポートメールアドレスを用意した場合は、`index.html` と `privacy.html` の「お問い合わせ」を更新し、再度commit・pushしてください。
- `b00kawa/sns-draft-book-support`（末尾 `-v2` なし）は別の既存リポジトリで、中身が旧アカウント時代のページのままのため、このアプリの公開先としては使用していません。混同しないよう注意してください。
